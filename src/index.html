            Zugang für privates Repository 
            
      
              Solange das Repository privat ist, braucht die App einen persönlichen GitHub-Zugangsschlüssel, der nur
              lesen darf. Einmalig einrichten:
            
      
            
        
              
      1. Diesen Link öffnen (bei GitHub angemeldet sein).
        2. 
              
      2. Bei Repository access: „Only select repositories“ → Funktrainer wählen.
        3. 
              
      3. Bei Permissions → Contents: „Read-only“ (ist vorausgewählt). Ablaufdatum möglichst lang.
        4. 
              
      4. Generate token klicken, den Schlüssel (beginnt mit github_pat_) kopieren und hier einfügen.

      Willkommen beim BOS Funktrainer 👋
      
        
      
          Hier trainierst du Sprechfunk wie im Einsatz: Die Gegenstellen sprechen mit dir, du antwortest über das Mikrofon
          und das simulierte Funkgerät – und bekommst nach jeder Sendung eine Bewertung.
        
      
        
      
          Neu hier oder lange nicht gefunkt? Das Tutorial (6 kurze Lektionen, ca. 20 Minuten) zeigt dir Schritt für
          Schritt die Bedienung des Geräts und die wichtigsten Regeln – mit Ausbilder und direkter Praxis.
        
      
        
      Tipp: Ein Headset verbessert die Spracherkennung deutlich.
